SRI VOGUE IMAGE SLOTS

The website intentionally displays designed image placeholders instead of repeating stock photos.
Add your images into these folders and then set each product's image field in src/products.js.

Products: public/images/products/your-image.jpg
Collections: public/images/collections/sarees.jpg, ethnic-sets.jpg, dresses.jpg, accessories.jpg
Hero campaign: public/images/hero.jpg
Editorial panel: public/images/editorial/brand-story.jpg

Example product record:
{
  "id": "SV001",
  "name": "Kanjivaram Silk Saree",
  "image": "/images/products/kanjivaram-silk-saree.jpg"
}

Use exact filenames and paths. Do not use the same image path for different products if you want every product to have its own image.
